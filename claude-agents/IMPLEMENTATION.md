# Claudia Azure WAF Agents Implementation

## Overview
This implementation integrates Azure WAF compliance agents into Claudia, providing a powerful GUI for managing specialized Azure agents.

## Prerequisites

### Required Software
- **Rust**: Will be auto-installed/updated if needed
- **Bun**: Will be auto-installed if missing
- **Claude Code CLI**: Install from https://claude.ai/code
- **Git**: For cloning Claudia repository

### Claudia Repository
The Claudia repository should be cloned to your local machine:
```bash
# Default location (can be customized via CLAUDIA_DIR environment variable)
git clone https://github.com/getAsterisk/claudia.git ~/Source/github.com.getAsterisk/claudia
```

## Installation

### Quick Start
```bash
# Make scripts executable
chmod +x *.sh

# Option 1: Update Rust and build everything (recommended)
./update-rust-and-build.sh

# Option 2: Just run setup (if Rust is already up to date)
./claudia-setup.sh
```

### Custom Claudia Location
If you cloned Claudia to a different location:
```bash
export CLAUDIA_DIR=/path/to/your/claudia
./claudia-setup.sh
```

## Scripts Included

### 1. `claudia-setup.sh`
Main setup script that:
- Checks prerequisites
- Builds Claudia from source
- Creates SQLite database
- Inserts all Azure WAF agents
- Creates launcher script
- Validates installation

### 2. `update-rust-and-build.sh`
Updates Rust and builds Claudia:
- Updates Rust to latest stable version
- Cleans previous build artifacts
- Rebuilds Claudia with latest dependencies
- Runs agent setup automatically

### 3. `validate-agents.sh`
Validates agent installation:
- Checks if all 5 agents are installed
- Validates agent configurations
- Reports any missing or misconfigured agents

### 4. `launch-claudia.sh` (generated)
Launches Claudia with integrated agents:
- Auto-generated by setup script
- Uses correct paths based on your environment

### 5. `export-agents.sh` (generated)
Exports agents from database:
- Extracts agent configurations as JSON
- Useful for backup or sharing

## Integrated Agents

### 1. Code Quality Agent
- **Icon**: 🔍 (search)
- **Purpose**: Enforce code quality standards and security compliance
- **Features**: OWASP scanning, coverage analysis, complexity assessment

### 2. WAF Documentation Agent
- **Icon**: 📚 (book)
- **Purpose**: Generate Microsoft Well-Architected Framework documentation
- **Features**: Auto-detects specialization, generates 6-10 core documents

### 3. Architecture Enforcement Agent
- **Icon**: 🏗️ (build)
- **Purpose**: Validate and enforce onion architecture patterns
- **Features**: Blocks violations, validates project references

### 4. Azure Infrastructure Agent
- **Icon**: ☁️ (cloud)
- **Purpose**: Generate Azure infrastructure with proper naming
- **Features**: Enforces Microsoft naming standards, generates Bicep templates

### 5. Audit Orchestration Agent
- **Icon**: 🎯 (target)
- **Purpose**: Coordinate audit readiness for Azure specializations
- **Features**: Detects specialization type, maps documents to controls

## Usage

### Launching Claudia
After successful installation:
```bash
./launch-claudia.sh
```

### Using Agents in Claudia
1. Open Claudia application
2. Navigate to "CC Agents" tab
3. Select an Azure WAF agent
4. Click "Run" and specify:
   - Project path
   - Task description (optional)
5. View execution results and logs

### Validating Installation
```bash
./validate-agents.sh
```

## Database Location
Agents are stored in SQLite database at:
```
~/Library/Application Support/claudia.asterisk.so/agents.db
```

## Troubleshooting

### Build Fails with Rust Version Error
```bash
# Update Rust to latest stable
rustup update stable
rustup default stable

# Then rebuild
./update-rust-and-build.sh
```

### Claudia Not Found
```bash
# Clone Claudia first
git clone https://github.com/getAsterisk/claudia.git ~/Source/github.com.getAsterisk/claudia

# Or set custom location
export CLAUDIA_DIR=/your/claudia/path
./claudia-setup.sh
```

### Agents Not Appearing in Claudia
1. Run validation script: `./validate-agents.sh`
2. Restart Claudia application
3. Check database directly:
   ```bash
   sqlite3 ~/Library/Application\ Support/claudia.asterisk.so/agents.db "SELECT name FROM agents;"
   ```

### Import/Export Issues
The Claudia import feature may be broken. Use direct database insertion via the setup script instead.

## Development

### Adding New Agents
1. Create agent JSON in `claudia-format/` directory
2. Run setup script to insert into database
3. Validate with `./validate-agents.sh`

### Agent JSON Format
```json
{
  "agent": {
    "name": "Agent Name",
    "icon": "icon_name",
    "model": "sonnet",
    "default_task": "Task description",
    "system_prompt": "Detailed system prompt..."
  },
  "version": 1,
  "exported_at": "2025-08-16T18:00:00.000000+00:00"
}
```
